Safester - What's New


v7.0 - April 23, 2026
  • Development has resumed in NetBeans 29 with OpenJDK 25 for compilation, execution, and installer packaging.
  • OpenPGP support has been restored with the lightweight Bouncy Castle library bcpg-jdk15on-1.51.jar.
  • Safester now targets Java 25.
  • A Windows installer is now available.
  • A Windows installer guide has been added.
  • A macOS installer is now available.
  • A macOS installer guide has been added.
  • Default font sizes have been improved.
  • The logo has been cleaned up.


v6.5 - March 26, 2024
  • When clicking on the Safester icon, the software now displays correctly.
  • It is now possible to request PDF encryption for downloaded PDFs using the Safester passphrase.


v6.3 - September 25, 2021
  • Windows only: it is now possible to change the scaling of the user interface from 100% to 250%.


v6.2.1 - June 22, 2021
  • Passphrase change screen: it is now possible to copy the passphrase for easy save after
  • Bug fix: There was a glitch on the French version when reporting an email address error on Register. This has been fixed.

v6.2 - June 19, 2021
  • It is now possible to copy the passphrase for easy save during account creation.

v6.1.1 - May 28, 2021
  • Bug fix: The second sound file would not play in Sound Picker. This has been fixed.
  • Bug fix: Search Windows was not set on default Inbox. This has been fixed.

v6.1 - May 27, 2021
  • The bright top Windows bar has been removed on the Windows version.
  • Bug fix: some small visual glitches have been fixed.

v6.0 - May 24, 2021
  • Message deletion options have been added.
  • Bug fix: some small visual glitches have been fixed.

v5.9.1 - May 21, 2021
  • Safester now supports Dark Mode with two themes.
  • User interface scaling has been added.
  • Bug fix: It was possible to create a subfolder in Starred. This has been fixed.
  • Bug fix: Starred could appear more than once. This has been fixed.
  • Bug fix: some other small visual glitches have been fixed.

v5.8 - May 15, 2021
  • The Windows installer is now strongly signed in order to avoid Microsoft SmartScreen "Blue Square".
  • The default Look & Feel theme is now Flatlaf IntelliJ on Windows, macOs & Linux.
  • A second theme is available: Arc Orange. See in Settings Menu.

v5.7.2 - February 22, 2021
  • A new option allows to request for confirmation before sending a message.
  • Bug fix: "No Print" and "No Forward" button activations were not visible on macOS. This has been fixed.
  • Bug fix: Users names were HTML encoded when doing a Reply or Reply All. This has been fixed.

v5.5 - October 28, 2019

v5.2 - September 9, 2019

v2.0 - March 30, 2018

  • Vacation responder does not accept activation if text zone is empty.
